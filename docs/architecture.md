# Architecture Overview

## Overview
This project is an iOS Fitness Coach app using SwiftUI and MVVM architecture.

## Modules
- **App/**: Main iOS app code
- **Core/**: Domain models and interfaces
- **Features/**: Feature-specific modules
- **Services/**: External service integrations
- **Infrastructure/**: Configuration, logging, networking
- **DesignSystem/**: UI components and themes
- **Tests/**: Test suites

## Technologies
- Swift 6, SwiftUI
- HealthKit, Vision, CoreML
